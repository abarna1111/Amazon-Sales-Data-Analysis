# Amazon Sales Data Analysis

## 📖 Description

This project contains Amazon sales data organized in an Excel dataset. It can be used to explore e-commerce sales information and identify useful patterns and business insights.

## 📊 Dataset

The project uses an Excel dataset containing Amazon-related sales data.

**File:**

* `Amazon.csv(1).xlsx`

## 🎯 Project Objectives

* Analyze Amazon sales data
* Explore product and sales-related information
* Identify useful patterns and trends
* Generate insights from the dataset
* Practice data analysis using Excel

## 🛠️ Tools Used

* Microsoft Excel
* GitHub

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `Amazon.csv(1).xlsx` using Microsoft Excel.
3. Explore and analyze the available data.
4. Use Excel features such as filtering, sorting, formulas, PivotTables, and charts for further analysis.
